A knowledge graph of the IPCC Sixth Assessment Report

A bibliographic foundation for the data science community to semantify climate science

ClimateKG has structured the Intergovernmental Panel on Climate Change’s Sixth Assessment Report (IPCC AR6) as a Wikibase knowledge graph.

The foundation is made of five datasets:

  1. Corpus: Structured hierarchy of AR6 reports, chapters, and text divisions; 7,524,958 words, 2,153 image files, 88 chapters, 7 reports, and a full text import into MediaWiki.
  2. Bibliography: Bibliographic information for AR6 reports and chapters; 95 DOIs.
  3. Glossary: Key AR6 terms and definitions for climate concepts; 1,274 terms.
  4. Acronyms: AR6 acronym index with expanded forms and references; 1,910 acronyms.
  5. Authors: Author identities and links to AR6 report/chapter contributions; 932 authors.

An invitation to data scientists

The graph acts as a structural (syntactic) framework for data scientists to add linked open data (LOD) about the scientific findings contained in the report.

How the knowledge graph is made

ClimateKG has made a software pipeline to structure corpora like the IPCC AR6.

Pipeline Formula

Web scrape → (full text + datasets) + Entity-Relationship model = knowledge graph (syntactic bibliographic foundation)

The AR6 report is web scraped from the IPCC AR6 website and follows a CSV → XML/DTD → Wikibase import pipeline. An Entity-Relationship Model (ER Model) maps every DTD element to a confirmed Wikibase property.
