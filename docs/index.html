Data Model & Pipeline

ClimateKG structures IPCC AR6 publications as a Wikibase knowledge graph. The data follows a CSV → XML/DTD → Wikibase pipeline, documented through an Entity-Relationship Model (ERM) that maps every DTD element to a confirmed Wikibase property (PID) or class item (QID).

## Data Model & Pipeline

ClimateKG structures IPCC AR6 publications as a Wikibase knowledge graph.
The data follows a **CSV → XML/DTD → Wikibase** pipeline, documented through
an Entity-Relationship Model (ERM) that maps every DTD element to a confirmed
Wikibase property (PID) or class item (QID).
